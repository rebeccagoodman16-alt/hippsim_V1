Your Minimal and Clean (Ceballos et al. 2025, as printed) notebooks, ported into one vectorized Python package and run through three experiments: a port check, a regime map over dendritic Ih, and a ZAP impedance protocol crossed with input site.

Findings

  • Verified
    The port reproduces your notebook. Minimal at I0 = 1 µA/cm² for 1 s gives 4 spikes in both implementations. Spike times agree within 0.015 ms at dt = 0.025 ms.
  • Model issue
    Minimal and Clean are different models. They disagree on Ih (Eh −30 vs −90 mV, activation slope sign, constant vs voltage-dependent τ) and on p∞, b∞, r∞, c∞, ḡNaP and ḡKdr.
  • Model issue
    As-printed never spikes; Minimal at ḡh = 8.46 is a pacemaker. As-printed rests near −82 mV at every ḡh, including 0. Minimal at 8.46 holds the dendrite at −48 mV and fires at I0 = 0, and −3 µA/cm² at the soma can't silence it. That value is most likely a units or scaling mismatch.
  • New result
    Dendritic Ih creates a resonance. With ḡh from 0 to 0.10 mS/cm², fres rises from 1 to 4 Hz and Q from 1.0 to 1.5. Dendrite → soma transfer has the highest Q. Reciprocity holds within 1.4%; at 0.15 it fails, so the cell has left the linear regime.

Regime map over dendritic Ih

Model

Cs dVs/dt = Is(t) − Σk Ik(Vs, x) − gac(Vs − Vd)
Cd dVd/dt = Id(t) − gL(Vd − EL) − ḡh hd(Vd − Eh) + gac(Vs − Vd)
dx/dt = (x∞(V) − x) / τx,   x∞(V) = 1 / (1 + exp(−(V − V½)/k))
d[Ca]/dt = −ν IHCa − [Ca]/τCa

Somatic currents: NaT, NaP, Kdr, A, M, HCa, fKCa, sKCa and leak. The dendrite carries leak and Ih. Every gate's half-activation and slope is stored as data in params.py, so the two variants differ only by dictionary entries. Any parameter can be an array of length N, which runs N neurons in one batch for about the cost of one.

Two variants exist in Rebecca's Drive and they are NOT the same model:

- MINIMAL  : CA1_HHca_TwoCompartment_Minimal.ipynb (2026-10-16).
             Conventional hyperpolarization-activated Ih (slope < 0),
             E_h = -30 mV, constant tau_h = 50 ms; p_inf half = -47 mV
             ("repository value").
- AS_PRINTED : CA1_HHca_Two_Compartment_Clean.ipynb (Ceballos et al. 2025,
             PLoS Comput Biol, doi:10.1371/journal.pcbi.1013126, Table 1 as printed).
             Ih activation slope > 0 (depolarization-activated), E_h = E_K,
             voltage-dependent tau.

Every kinetic constant is data here, so variants differ only by dict entries.
Units: mV, ms, mS/cm^2, uA/cm^2, uF/cm^2. Calcium in model units.
"""

"""
Vectorized two-compartment CA1 HHca model.

State y has shape (11, N): N independent neurons simulated in one batch.
Any parameter may be a scalar or an (N,) array -> sweeps and heterogeneous
populations cost one vectorized run instead of N Python loops.

Equations (soma s, dendrite d):

    C_s dV_s/dt = I_s(t) - sum_k I_k(V_s, x) - g_ac (V_s - V_d)
    C_d dV_d/dt = I_d(t) - g_L (V_d - E_L) - g_h h_d (V_d - E_h) + g_ac (V_s - V_d)
    dx/dt       = (x_inf(V) - x) / tau_x
    d[Ca]/dt    = -nu I_HCa - [Ca]/tau_Ca
"""
import numpy as np

STATE_NAMES = ["Vs", "Vd", "h", "n", "b", "z", "r", "c", "Ca", "q", "hd"]
IDX = {k: i for i, k in enumerate(STATE_NAMES)}


# ---------------------------------------------------------------- gating
def gate_inf(v, half, slope):
    """Boltzmann steady state 1 / (1 + exp(-(v - half)/slope)), overflow-safe."""
    return 1.0 / (1.0 + np.exp(np.clip(-(v - half) / slope, -700, 700)))


def tau_h_na(v):
    return 0.1 + 0.75 * gate_inf(v, -40.5, -6.0)


def tau_n(v):
    return 0.1 + 0.5 * gate_inf(v, -27.0, -15.0)


def tau_hd(v, p):
    if p["hh_tau_mode"] == "const":
        return p["hh_tau"]
    return 1.0 / (np.exp(-17.9 + 0.116 * v) + np.exp(-1.84 + 0.09 * v)) + 0.1


def steady_gates(v, p):
    """All voltage-gated steady states at somatic voltage v."""
    g = lambda k: gate_inf(v, p[f"{k}_half"], p[f"{k}_slope"])
    return {k: g(k) for k in ("m", "h", "n", "p", "a", "b", "z", "r", "c")}


# ---------------------------------------------------------------- currents
def soma_currents(y, p):
    """Somatic ionic currents (outward positive), dict of arrays."""
    vs, ca = y[IDX["Vs"]], np.maximum(y[IDX["Ca"]], 1e-12)
    s = steady_gates(vs, p)
    d_inf = ca / (p["ac"] + ca)
    return dict(
        L=p["gL"] * (vs - p["EL"]),
        NaT=p["gNaT"] * s["m"] ** 3 * y[IDX["h"]] * (vs - p["ENa"]),
        NaP=p["gNaP"] * s["p"] * (vs - p["ENa"]),
        Kdr=p["gKdr"] * y[IDX["n"]] ** 4 * (vs - p["EK"]),
        A=p["gA"] * s["a"] ** 3 * y[IDX["b"]] * (vs - p["EK"]),
        M=p["gM"] * y[IDX["z"]] * (vs - p["EK"]),
        HCa=p["gHCa"] * y[IDX["r"]] ** 2 * (vs - p["ECa"]),
        fKCa=p["gfKCa"] * d_inf * y[IDX["c"]] * (vs - p["EK"]),
        sKCa=p["gsKCa"] * y[IDX["q"]] * (vs - p["EK"]),
    )


def dend_currents(y, p):
    vd = y[IDX["Vd"]]
    return dict(
        L=p["gL_d"] * (vd - p["EL"]),
        h=p["gh"] * y[IDX["hd"]] * (vd - p["Eh"]),
    )


# ---------------------------------------------------------------- RHS
def rhs(t, y, p, I_s, I_d):
    """dy/dt for batch state y (11, N). I_s, I_d: callables t -> scalar or (N,)."""
    vs, vd, ca = y[IDX["Vs"]], y[IDX["Vd"]], np.maximum(y[IDX["Ca"]], 1e-12)
    s = steady_gates(vs, p)
    i_s = soma_currents(y, p)
    i_d = dend_currents(y, p)
    i_ax = p["gac"] * (vs - vd)
    q_inf = ca**4 / (p["aq"] ** 4 + ca**4)

    dy = np.empty_like(y)
    dy[IDX["Vs"]] = (I_s(t) - sum(i_s.values()) - i_ax) / p["Cm_s"]
    dy[IDX["Vd"]] = (I_d(t) - sum(i_d.values()) + i_ax) / p["Cm_d"]
    dy[IDX["h"]] = (s["h"] - y[IDX["h"]]) / tau_h_na(vs)
    dy[IDX["n"]] = (s["n"] - y[IDX["n"]]) / tau_n(vs)
    dy[IDX["b"]] = (s["b"] - y[IDX["b"]]) / p["tau_b"]
    dy[IDX["z"]] = (s["z"] - y[IDX["z"]]) / p["tau_z"]
    dy[IDX["r"]] = (s["r"] - y[IDX["r"]]) / p["tau_r"]
    dy[IDX["c"]] = (s["c"] - y[IDX["c"]]) / p["tau_c"]
    dy[IDX["Ca"]] = -p["nu"] * i_s["HCa"] - ca / p["tauCa"]
    dy[IDX["q"]] = (q_inf - y[IDX["q"]]) / p["tau_q"]
    dy[IDX["hd"]] = (gate_inf(vd, p["hh_half"], p["hh_slope"]) - y[IDX["hd"]]) / tau_hd(vd, p)
    return dy


def initial_state(p, n=1, vs=-72.0, vd=-72.0):
    """Steady-state gates at the starting voltages, broadcast to (11, n)."""
    vs = np.broadcast_to(np.asarray(vs, float), (n,)).copy()
    vd = np.broadcast_to(np.asarray(vd, float), (n,)).copy()
    s = steady_gates(vs, p)
    ca = np.full(n, p["Ca0"], float)
    y = np.vstack([
        vs, vd, s["h"], s["n"], s["b"], s["z"], s["r"], s["c"], ca,
        ca**4 / (p["aq"] ** 4 + ca**4),
        gate_inf(vd, p["hh_half"], p["hh_slope"]),
    ])
    return np.broadcast_to(y, (11, n)).astype(float).copy()


# ---------------------------------------------------------------- integrator
def simulate(p, duration_ms, I_s=None, I_d=None, n=1, dt=0.02, record_dt=0.1,
             y0=None, record=("Vs", "Vd"), noise_D=0.0, seed=0):
    """
    Fixed-step RK4 for a batch of n neurons.

    noise_D > 0 adds somatic white noise sqrt(2 D dt) xi / C_m after each step
    (same scheme as simulate_with_noise in the Clean notebook).

    Returns t (T,), traces dict name -> (T, n).
    """
    zero = lambda t: 0.0
    I_s, I_d = I_s or zero, I_d or zero
    y = initial_state(p, n) if y0 is None else np.array(y0, float)
    rng = np.random.default_rng(seed)

    n_steps = int(round(duration_ms / dt))
    stride = max(1, int(round(record_dt / dt)))
    n_rec = n_steps // stride + 1
    out = {k: np.empty((n_rec, n)) for k in record}
    for k in record:
        out[k][0] = y[IDX[k]]

    f = lambda t, y: rhs(t, y, p, I_s, I_d)
    t, j = 0.0, 1
    for step in range(1, n_steps + 1):
        k1 = f(t, y)
        k2 = f(t + dt / 2, y + dt / 2 * k1)
        k3 = f(t + dt / 2, y + dt / 2 * k2)
        k4 = f(t + dt, y + dt * k3)
        y = y + dt / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
        if noise_D:
            y[IDX["Vs"]] += np.sqrt(2 * noise_D * dt) * rng.standard_normal(n) / p["Cm_s"]
        t = step * dt
        if step % stride == 0:
            for k in record:
                out[k][j] = y[IDX[k]]
            j += 1
    if not np.isfinite(y).all():
        raise FloatingPointError("Non-finite state: reduce dt or inspect parameters.")
    t_rec = np.arange(n_rec) * stride * dt
    return t_rec, out, y

"""Input currents (uA/cm^2). Each factory returns a callable t_ms -> value(s)."""
import numpy as np


def constant(I0):
    return lambda t: I0


def sinusoids(I0=0.0, components=()):
    """I0 + sum A sin(2 pi f t + phi); components = [(A, f_Hz, phi_rad), ...]."""
    def f(t):
        return I0 + sum(A * np.sin(2 * np.pi * fz * t / 1000.0 + ph) for A, fz, ph in components)
    return f


def zap(amp, f0=0.5, f1=20.0, T_ms=10000.0, I0=0.0, t_on=500.0):
    """
    Linear chirp (ZAP): I(t) = I0 + amp sin(2 pi [f0 tau + (f1-f0) tau^2 / (2T)]),
    tau = (t - t_on)/1000 s, active for t_on <= t < t_on + T.
    """
    T = T_ms / 1000.0
    def f(t):
        tau = (t - t_on) / 1000.0
        if tau < 0 or tau >= T:
            return I0
        return I0 + amp * np.sin(2 * np.pi * (f0 * tau + (f1 - f0) * tau**2 / (2 * T)))
    return f


def masked(fn, mask):
    """Apply a stimulus only to neurons where mask (N,) is 1 -> per-site injection in a batch."""
    mask = np.asarray(mask, float)
    return lambda t: fn(t) * mask

"""Spike, rhythm and frequency-response metrics."""
import numpy as np
from scipy import signal


# ---------------------------------------------------------------- spikes
def spike_times(t, v, thr=0.0):
    """Upward threshold crossings, linearly interpolated (same as Clean notebook)."""
    i = np.flatnonzero((v[:-1] < thr) & (v[1:] >= thr))
    return t[i] + (t[i + 1] - t[i]) * (thr - v[i]) / (v[i + 1] - v[i])


def rate_cv(spk, duration_ms):
    isi = np.diff(spk)
    rate = len(spk) / (duration_ms / 1000.0)
    cv = isi.std() / isi.mean() if len(isi) >= 2 else np.nan
    return rate, cv


def vector_strength(spk, f_hz, phase0=0.0):
    """R = |<exp(i phi_k)>|, phi_k = 2 pi f t_k + phase0. Returns (R, preferred phase)."""
    if len(spk) == 0:
        return np.nan, np.nan
    z = np.exp(1j * (2 * np.pi * f_hz * np.asarray(spk) / 1000.0 + phase0)).mean()
    return np.abs(z), np.angle(z)


# ---------------------------------------------------------------- impedance
def impedance(I, V, fs_hz, nperseg_s=4.0, fmin=1.0, fmax=20.0):
    """
    H1 estimator Z(f) = S_IV(f) / S_II(f) (Welch-averaged), units MOhm*cm^2 -> kOhm*cm^2
    when I in uA/cm^2 and V in mV (mV / uA = kOhm).
    Returns f, Z (complex) restricted to [fmin, fmax]. Keep fmin above the
    lowest frequency the chirp sweeps through for several cycles.
    """
    I = np.asarray(I) - np.mean(I)
    V = np.asarray(V) - np.mean(V)
    nper = int(nperseg_s * fs_hz)
    f, Sii = signal.welch(I, fs_hz, nperseg=nper)
    _, Siv = signal.csd(I, V, fs_hz, nperseg=nper)
    keep = (f >= fmin) & (f <= fmax)
    return f[keep], Siv[keep] / Sii[keep]


def resonance_metrics(f, Z):
    """f_res = argmax |Z|, Q = |Z(f_res)| / |Z(lowest analysed f)|, phase at f_res (deg).
    Q = 1 means no resonance within the analysed band (low-pass)."""
    a = np.abs(Z)
    k = np.argmax(a)
    return dict(f_res=f[k], Q=a[k] / a[0], Zmax=a[k], phase_deg=np.degrees(np.angle(Z[k])))

"""
Subthreshold frequency response: g_h (dendritic Ih) x injection site (soma / dendrite).

Protocol: ZAP 0.5 -> 20 Hz, 10 s, amplitude 0.05 uA/cm^2, I0 = 0, Minimal variant.
Batch layout: neuron j = (gh_k, site) -> one vectorized run.

Measured (H1 estimator, Z = S_IV / S_II, analysed 1-20 Hz):
  site = soma     : Z_ss (input),    Z_ds (soma -> dendrite transfer)
  site = dendrite : Z_dd (input),    Z_sd (dendrite -> soma transfer)

Linearity diagnostic: for a linear(ised) system, reciprocity requires Z_ds == Z_sd.
Rows where max relative mismatch > RECIP_TOL are flagged nonlinear: Z(f) is not
a valid description there (cell near an instability / generating its own rhythm).
"""
import sys
from pathlib import Path
import numpy as np
import pandas as pd
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))
from ca1lab import get_params, simulate, stimuli, analysis

GH = np.array([0.0, 0.03, 0.06, 0.10, 0.15])
SITES = ("soma", "dend")
AMP, T_ZAP, T_ON, DT = 0.05, 10000.0, 500.0, 0.05
RECIP_TOL = 0.05
CACHE = ROOT / "figures" / "impedance_traces.npz"

gh = np.repeat(GH, 2)                         # [g0 soma, g0 dend, g1 soma, ...]
site = np.tile(SITES, len(GH))
zap = stimuli.zap(AMP, 0.5, 20.0, T_ZAP, t_on=T_ON)

# ---------------------------------------------------------------- simulate (cached)
if CACHE.exists():
    d = np.load(CACHE)
    t, tr = d["t"], {"Vs": d["Vs"], "Vd": d["Vd"]}
else:
    p = get_params("minimal", gh=gh)
    t, tr, _ = simulate(p, T_ON + T_ZAP,
                        I_s=stimuli.masked(zap, site == "soma"),
                        I_d=stimuli.masked(zap, site == "dend"),
                        n=len(gh), dt=DT, record_dt=0.5)
    np.savez_compressed(CACHE, t=t, gh=gh, site=site, **tr)

# ---------------------------------------------------------------- analyse
win = t >= T_ON
I = np.array([zap(tt) for tt in t[win]])
fs = 1000.0 / (t[1] - t[0])
LAB = {("soma", "Vs"): "Z_ss", ("soma", "Vd"): "Z_ds",
       ("dend", "Vd"): "Z_dd", ("dend", "Vs"): "Z_sd"}
curves, rows = {}, []
for j in range(len(gh)):
    for rec in ("Vs", "Vd"):
        f, Z = analysis.impedance(I, tr[rec][win, j], fs)
        lab = LAB[(site[j], rec)]
        curves[(gh[j], lab)] = (f, Z)
        rows.append(dict(gh=gh[j], measure=lab, V_rest=tr[rec][t < T_ON, j][-1],
                         spikes=len(analysis.spike_times(t, tr["Vs"][:, j])),
                         **analysis.resonance_metrics(f, Z)))
df = pd.DataFrame(rows)
recip = {g: np.max(np.abs(curves[(g, "Z_ds")][1] - curves[(g, "Z_sd")][1])
                   / np.abs(curves[(g, "Z_ds")][1])) for g in GH}
df["recip_err"] = df.gh.map(recip)
df["linear"] = df.recip_err < RECIP_TOL
df.to_csv(ROOT / "figures" / "impedance_summary.csv", index=False)
print(df.round(3).to_string(index=False))

# ---------------------------------------------------------------- figure
plt.rcParams.update({"font.size": 10, "axes.spines.top": False, "axes.spines.right": False})
cmap = plt.cm.viridis(np.linspace(0, 0.9, len(GH)))
fig, ax = plt.subplots(2, 4, figsize=(16, 7))
panels = [("Z_ss", "Soma input  $|Z_{ss}|$"), ("Z_dd", "Dendrite input  $|Z_{dd}|$"),
          ("Z_sd", "Dendrite$\\to$soma  $|Z_{sd}|$")]
for c, (key, title) in enumerate(panels):
    for k, g in enumerate(GH):
        if not recip[g] < RECIP_TOL:
            continue                                   # nonlinear: Z(f) invalid
        f, Z = curves[(g, key)]
        ax[0, c].plot(f, np.abs(Z), color=cmap[k], label=f"$\\bar g_h$ = {g:.2f}")
        ax[1, c].plot(f, np.degrees(np.angle(Z)), color=cmap[k])
    ax[0, c].set_title(title)
    ax[1, c].axhline(0, color="k", lw=0.5)
    ax[1, c].set_xlabel("Frequency (Hz)")
    for r in (0, 1):
        ax[r, c].axvspan(4, 12, color="0.93", zorder=0)
ax[0, 0].set_ylabel("|Z|  (k$\\Omega\\cdot$cm$^2$)")
ax[1, 0].set_ylabel("Phase (deg)")
ax[0, 0].legend(frameon=False, fontsize=8, title="linear regime", title_fontsize=8)

# Summary column: resonance frequency and Q vs g_h, per measure
for key, mk in (("Z_ss", "o"), ("Z_dd", "s"), ("Z_sd", "^")):
    sub = df[(df.measure == key) & df.linear]
    ax[0, 3].plot(sub.gh, sub.f_res, marker=mk, label=key.replace("Z_", "$Z_{") + "}$")
    ax[1, 3].plot(sub.gh, sub.Q, marker=mk)
ax[0, 3].set(title="Resonance vs $\\bar g_h$", ylabel="$f_{res}$ (Hz)")
ax[1, 3].set(xlabel="$\\bar g_h$ (mS/cm$^2$)", ylabel="Q = |Z(f_res)| / |Z(1 Hz)|")
ax[1, 3].axhline(1, color="k", lw=0.5)
ax[0, 3].legend(frameon=False, fontsize=8)
bad = [f"{g:.2f}" for g in GH if not recip[g] < RECIP_TOL]
fig.suptitle("CA1 two-compartment (Minimal): dendritic Ih density x input site  |  ZAP 0.5-20 Hz, I0 = 0"
             + (f"\n$\\bar g_h$ = {', '.join(bad)} omitted: reciprocity fails (nonlinear)" if bad else ""),
             fontweight="bold")
fig.tight_layout()
out = ROOT / "figures" / "impedance_gh_site.png"
fig.savefig(out, dpi=200)
print("reciprocity:", {f"{g:.2f}": round(e, 3) for g, e in recip.items()})
print("saved", out)
