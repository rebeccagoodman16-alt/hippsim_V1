Hodgkin–Huxley neuron

Four coupled ODEs: voltage plus three gating variables. The spike is a voltage-gated race: fast Na⁺ activation (m) wins first, then slow Na⁺ inactivation (h) and K⁺ activation (n) pull the membrane back.

Equations

\[C_m\frac{dV}{dt}=I_{ext}-\bar g_{Na}m^3h\,(V-E_{Na})-\bar g_K n^4(V-E_K)-g_L(V-E_L)\] \[\frac{dx}{dt}=\alpha_x(V)(1-x)-\beta_x(V)\,x,\qquad x\in\{m,h,n\}\]

Integrated with forward Euler, \(\Delta t = 0.01\) ms. Squid-axon constants, \(E_{Na}=50,\ E_K=-77\) mV.

Try this

  1. Read the f–I curve: firing jumps from 0 to ~60 Hz. That discontinuity is a subcritical Hopf (type II excitability). There is no arbitrarily slow firing.
  2. Push Iext to ~35. Firing stops: depolarization block, as Na⁺ channels stay inactivated (watch h sit low).
  3. Drop K⁺ to 0.4×. Spikes broaden and repolarization fails. Relevant to Aβ-linked K⁺ channel changes in AD hyperexcitability.
Same model in Python (Brian2)
from brian2 import *

Cm = 1*uF/cm**2
gNa, gK, gL = 120*msiemens/cm**2, 36*msiemens/cm**2, 0.3*msiemens/cm**2
ENa, EK, EL = 50*mV, -77*mV, -54.387*mV

eqs = '''
dv/dt = (I - gNa*m**3*h*(v-ENa) - gK*n**4*(v-EK) - gL*(v-EL)) / Cm : volt
dm/dt = am*(1-m) - bm*m : 1
dh/dt = ah*(1-h) - bh*h : 1
dn/dt = an*(1-n) - bn*n : 1
am = 0.1/mV*(v+40*mV) / (1-exp(-(v+40*mV)/(10*mV))) / ms : Hz
bm = 4*exp(-(v+65*mV)/(18*mV)) / ms : Hz
ah = 0.07*exp(-(v+65*mV)/(20*mV)) / ms : Hz
bh = 1 / (1+exp(-(v+35*mV)/(10*mV))) / ms : Hz
an = 0.01/mV*(v+55*mV) / (1-exp(-(v+55*mV)/(10*mV))) / ms : Hz
bn = 0.125*exp(-(v+65*mV)/(80*mV)) / ms : Hz
I : amp/meter**2
'''
G = NeuronGroup(1, eqs, method='exponential_euler',
                threshold='v > 0*mV', refractory='v > 0*mV')
G.v, G.m, G.h, G.n = -65*mV, 0.053, 0.596, 0.318
mon = StateMonitor(G, ['v', 'm', 'h', 'n'], record=0)
run(10*ms); G.I = 10*uA/cm**2; run(80*ms); G.I = 0*uA/cm**2; run(10*ms)

Equations

\[\tau\frac{dV_i}{dt}=-V_i+\tau\sum_j J_{ij}\sum_k\delta\!\left(t-t_j^k-D\right)\] \[J_{ij}\in\{J,\,-gJ\},\quad V_i\ge\theta\Rightarrow V_i\to V_r,\quad \nu_{thr}=\frac{\theta}{J\,C_E\,\tau}\]

\(\tau=20\) ms, \(\theta=20\) mV, \(V_r=10\) mV, \(D=1.5\) ms, \(J=0.5\) mV, \(C_E=200,\ C_I=50\). Synchrony \(\chi^2=\sigma^2_{\bar V}/\langle\sigma^2_{V_i}\rangle\). This is a small network, so regime boundaries shift from the paper's \(N=12{,}500\).

Try this

  1. Click SR then AI. Same drive; inhibition-dominance alone turns lockstep firing (CV ≈ 0) into Poisson-like irregularity (CV ≈ 1).
  2. Sweep g from 3 to 6 at η = 2 and note where CV crosses 0.5: that is the balanced-state transition.
  3. AD link: a loss of interneuron efficacy ≈ lowering g. Watch the rate climb as the circuit drifts into hyperexcitability.
Same model in Python (Brian2)
from brian2 import *

NE, NI = 800, 200
CE, CI = 200, 50
tau, theta, Vr, D, J = 20*ms, 20*mV, 10*mV, 1.5*ms, 0.5*mV
g, eta = 5.0, 2.0
nu_thr = theta / (J * CE * tau)

G = NeuronGroup(NE + NI, 'dv/dt = -v/tau : volt (unless refractory)',
                threshold='v > theta', reset='v = Vr',
                refractory=2*ms, method='exact')
G.v = 'rand() * theta'

SE = Synapses(G[:NE], G, on_pre='v_post += J', delay=D)
SE.connect(p=CE / NE)          # Brunel uses fixed in-degree; p approximates it
SI = Synapses(G[NE:], G, on_pre='v_post += -g*J', delay=D)
SI.connect(p=CI / NI)
ext = PoissonInput(G, 'v', N=CE, rate=eta * nu_thr, weight=J)

spikes = SpikeMonitor(G)
rate = PopulationRateMonitor(G)
run(400*ms)

Wilson–Cowan mean field

Average the spikes away: two variables, E and I, are the active fractions of each population. Now the full geometry is visible. Nullclines, fixed points, a limit cycle, and the Hopf bifurcation where oscillations are born. Click the phase plane to launch a trajectory.

Equations

\[\tau_E\dot E=-E+S_E(w_{EE}E-w_{EI}I+P),\qquad \tau_I\dot I=-I+S_I(w_{IE}E-w_{II}I+Q)\] \[S(x)=\frac{1}{1+e^{-a(x-\theta)}}-\frac{1}{1+e^{a\theta}}\] \[\lambda_{1,2}=\tfrac12\left(\operatorname{tr}\mathbf J\pm\sqrt{(\operatorname{tr}\mathbf J)^2-4\det\mathbf J}\right)\]

RK4, \(\Delta t=0.05\). Fixed points by bisection along the E-nullcline; Jacobian by central differences. Hopf: \(\operatorname{tr}\mathbf J\) crosses 0 with \(\det\mathbf J>0\).

Try this

  1. Slide P slowly through ~1.0. The fixed point flips from stable to unstable focus and a limit cycle appears. Compare the readout eigenvalues with the bifurcation plot.
  2. Raise τI to 2–3. Slower inhibition gives larger, slower oscillations, the same mechanism behind PING gamma rhythms.
  3. Raise wEE to ~20 with low P. Multiple fixed points appear (bistability, a working-memory-like "up state"). Click on both sides of the saddle.
Same analysis in Python (NumPy / SciPy)
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import fsolve

def S(x, a, th):
    return 1/(1 + np.exp(-a*(x - th))) - 1/(1 + np.exp(a*th))

p = dict(wEE=16, wEI=12, wIE=15, wII=3, aE=1.3, thE=4, aI=2, thI=3.7,
         P=1.25, Q=0.0, tauE=1.0, tauI=1.0)

def rhs(t, z, p):
    E, I = z
    dE = (-E + S(p['wEE']*E - p['wEI']*I + p['P'], p['aE'], p['thE'])) / p['tauE']
    dI = (-I + S(p['wIE']*E - p['wII']*I + p['Q'], p['aI'], p['thI'])) / p['tauI']
    return [dE, dI]

sol = solve_ivp(rhs, (0, 100), [0.1, 0.05], args=(p,), max_step=0.05)

# fixed point + linear stability
fp = fsolve(lambda z: rhs(0, z, p), [0.2, 0.1])
h = 1e-6
J = np.column_stack([(np.array(rhs(0, fp + h*e, p)) - np.array(rhs(0, fp - h*e, p))) / (2*h)
                     for e in np.eye(2)])
print(fp, np.linalg.eigvals(J))

Spike-timing-dependent plasticity

Now the weights move. One LIF neuron receives 100 Poisson inputs at 10 Hz; inputs 1–50 share correlated spikes. Pre-before-post potentiates, post-before-pre depresses. With depression slightly stronger, inputs compete and the correlated group takes over the neuron.

Equations

\[\Delta w=\begin{cases}A_+\,e^{-\Delta t/\tau_+}, & \Delta t>0\\ -A_-\,e^{\Delta t/\tau_-}, & \Delta t<0\end{cases}\qquad 0\le w\le w_{max}\] \[\dot x_i=-\frac{x_i}{\tau_+}+\sum_k\delta(t-t_i^k),\qquad \dot y=-\frac{y}{\tau_-}+\sum_k\delta(t-t_{post}^k)\]

All-to-all pairing via traces: on post spike \(w_i \mathrel{+}= A_+x_i\), on pre spike \(w_i \mathrel{-}= A_-y\). Additive rule with hard bounds, after Song, Miller & Abbott (2000).

Try this

  1. Set c = 0 and train. With no structure to find, depression wins and the output rate falls, a homeostatic effect of the rule itself.
  2. Lower A−/A+ below 1. Everything potentiates to wmax: runaway Hebbian excitation, no selectivity.
  3. Compare with the MLP tab: here the "error signal" is purely local timing, not a backpropagated gradient.
Same model in Python (Brian2)
from brian2 import *

N, wmax, tau = 100, 0.06, 20*ms
Apre = 0.005 * wmax
Apost = -Apre * 1.2            # A-/A+ ratio

inputs = PoissonGroup(N, rates=10*Hz)   # swap in correlated trains for group A
post = NeuronGroup(1, 'dv/dt = -v/(20*ms) : 1', threshold='v > 1', reset='v = 0')

S = Synapses(inputs, post,
    '''w : 1
       dapre/dt = -apre/tau : 1 (event-driven)
       dapost/dt = -apost/tau : 1 (event-driven)''',
    on_pre='''v_post += w
              apre += Apre
              w = clip(w + apost, 0, wmax)''',
    on_post='''apost += Apost
               w = clip(w + apre, 0, wmax)''')
S.connect()
S.w = 'wmax * (0.4 + 0.2*rand())'
wmon = StateMonitor(S, 'w', record=True, dt=1*second)
run(300*second)

Equations

\[\hat y=\sigma\!\big(W_L\,\phi(\cdots\phi(W_1\mathbf x+\mathbf b_1)\cdots)+b_L\big)\] \[\mathcal L=-\frac1N\sum_{n}\big[y_n\log\hat y_n+(1-y_n)\log(1-\hat y_n)\big]\] \[\boldsymbol\delta^{(l)}=\big(W^{(l+1)\top}\boldsymbol\delta^{(l+1)}\big)\odot\phi'(\mathbf z^{(l)}),\qquad \frac{\partial\mathcal L}{\partial W^{(l)}}=\boldsymbol\delta^{(l)}\mathbf a^{(l-1)\top}\]

Full-batch Adam (\(\beta_1=0.9,\ \beta_2=0.999\)), 300 points. Note \(\boldsymbol\delta\) needs the transposed forward weights, the "weight transport problem" that makes backprop biologically implausible.

Try this

  1. Spiral with width 2: it cannot be solved. Raise width or depth until it can, and count the parameters you needed.
  2. Switch to ReLU and watch the boundary become piecewise linear. Each kink is a hidden unit switching on.
  3. Set lr to −0.5 (≈0.3). Loss oscillates or diverges, the same stability argument as \(\Delta t\) in an ODE integrator.
Same model in Python (PyTorch)
import torch
import torch.nn as nn

def make_mlp(width=12, depth=2, act=nn.Tanh):
    """Build 2 -> [width]*depth -> 1 MLP; outputs logits."""
    layers, d = [], 2
    for _ in range(depth):
        layers += [nn.Linear(d, width), act()]
        d = width
    return nn.Sequential(*layers, nn.Linear(d, 1))

model = make_mlp()
opt = torch.optim.Adam(model.parameters(), lr=10**-1.7)
loss_fn = nn.BCEWithLogitsLoss()          # sigmoid + BCE, numerically stable

for epoch in range(2000):                  # X: (N, 2) float, y: (N,) float
    opt.zero_grad()
    loss = loss_fn(model(X).squeeze(-1), y)
    loss.backward()                        # autograd does the δ recursion
    opt.step()
